# BigRich937 brand mark

**Universal mark — not tied to one project.** A gold **Я x R** monogram in Cinzel: the
first R is mirrored so the two R's frame the center, two crossed royal scepters form the
"x", and a ruby pin sits at the center. It represents **BigRich937** as a whole and is
used across every project: the **RRx token**, **RR Delivery**, and **RR Creator** — not
just one of them. Use it as the account avatar, in READMEs, on websites, and as the
favicon for anything under the BigRich937 name.

| File | Use |
|------|-----|
| `mark.svg` / `-1024.png` / `-512.png` / `-256.png` | Full mark: README header, website, app store art |
| `icon.svg` / `-512.png` / `-64.png` / `-32.png` | Monogram only, enlarged for small sizes: app icon, social profile picture |
| `favicon.ico` | Multi-size (16–256px) browser-tab icon |

Both files are centered and scaled so every corner stays inside the circle that GitHub,
Discord, X/Twitter, and most app icons crop square avatars to. Background is transparent,
so it works on dark and light. Below ~32px the fine linework gets hard to resolve — that's
a detail-level limit, not a centering issue.

**To set this as your actual GitHub account avatar:** upload `icon-512.png` (or `mark-512.png`
if you want the fuller composition) at https://github.com/settings/profile — that's a manual
upload step GitHub doesn't expose through the API, so it has to be done by hand.

## Source

These are built from the same generator as the RRx token's brand kit
(`BigRich937/rrx-token`, `brand/tools/`) — see that repo for the font-option exploration
history and the regeneration scripts. This folder holds the canonical copy for anything
that isn't token-specific.
